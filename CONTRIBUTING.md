# Contributing to Mango

Thank you for your interest in **Mango**!

This repository holds the C++ engine and console server behind the Mango Streaming Server apps. It's published as **source-available** under the [PolyForm Noncommercial License 1.0.0](LICENSE.md), so you can inspect the code, check what it does on your network, and build it for personal use.

## Pull Requests

External Pull Requests are not accepted and are closed automatically. If you want to modify the code for yourself, please fork the repository under the PolyForm Noncommercial License 1.0.0.

## Bug Reports

Bug reports are always welcome in the **Issues** tab. Please include:
* Your OS version (macOS or Windows build, or Linux distribution and version)
* Whether you used an app (and its version), the console server or the Linux service
* Your streaming target (Chromecast model or AirPlay device, or the player you opened a `stream` URL in)
* Container and codec details of the file that failed to play
* The `mango.log` from the stream's folder, if you have it

## Security Issues

Please don't open a public issue for a security problem. Report it privately with **Report a vulnerability** on the repository's **Security** tab.

## Commercial Use

For commercial use, or any use the license doesn't cover, contact the maintainer through GitHub.
